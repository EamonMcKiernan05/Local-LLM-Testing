# 09 — v0.1.40.1 → v0.1.40.2: parity on this box (2026-10-07)

The day's second update (0.1.39 → 0.1.40.1 → 0.1.40.2 in one day). Same method as 06/08: a
day-matched before/after on the standard battery. The 0.1.40.1 side is the morning run from
experiment 08 (same day, same config as served); the 0.1.40.2 side was measured after the update.
Both sides ran with the same start flags — only the engine differs.

0.1.40.2's headline items mostly target other setups: the multi-GPU split placement fix (examples
are 3–4 GPUs), the low-RAM page-cache file tier (this box keeps both expert caches ~fully
resident — 99.5 % decode hits — so the file tier is barely exercised), the prompt-stager sleep
fix, the verify-window optimization (explicitly "RTX 30 series and newer"), and Intel Arc
support. Expected: parity — and that is what measured.

−9 % to +2 % per cell, inside the ±5–8 % single-rep band. No material change either way — the
0.1.40.2 engine is a drop-in on this rig.

## Update procedure (as usual)

1. Stop the engine (`kill -TERM <serve/server.py pid>`), verify VRAM drops.
2. `git fetch origin --tags --force && git checkout v0.1.40.2`.
3. `STRATA_EXPERIMENTAL_SM60=1 ./setup.sh --update` — engine + vision rebuilt (~4 min), configs
   byte-identical, server not started.
4. Start with `STRATA_EXPERIMENTAL_SM60=1` only (`~/strata-start.sh`).
