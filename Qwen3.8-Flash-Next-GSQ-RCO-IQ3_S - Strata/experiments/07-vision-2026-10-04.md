# 07 — Vision enabled: the base model reads images (2026-10-04)

Strata's vision path on this box: a separate helper (`strata-vision`, llama.cpp's mtmd) plus the
model's mmproj GGUF. The base IQ3_S was re-set-up with `--vision gpu` — no download, the mmproj
(866 MB, BF16) was already in the model folder. The config gained a `vision` block and the args
`--vision --vram-reserve-mib 700`; on Volta the same run also rebuilds the engine into the
CUDA-12 layout (`engine-cuda12/`). ~6.5 min of build time, mostly the encoder.

## Verified, end-to-end (real requests)

- **Image test — read back exactly.** An 800×600 test image (text "STRATA VISION OK 417" plus
  blue rectangle, green triangle, red circle): all of it correct. 4.0 s wall, 549 prompt tokens
  at 302 tok/s, decode 93 tok/s, 99.5 % decode-cache hits.
- **Text regression, 20K-token prompt:** prefill 1,228 tok/s (−4.5 % vs the 1,286 no-vision run
  that morning — the cost of the VRAM reserve) and 77.9 tok/s decode (no-vision: 73.9; within
  run noise).

The encoder holds ~1.2 GB VRAM plus the 700 MiB reserve. A picture becomes up to 1,024 tokens
of context on GPU (`vision.max_tokens`; a 640×480 photo lands ~300).

## How to send an image

OpenAI-compatible API:

```python
import base64
from openai import OpenAI
client = OpenAI(base_url="http://192.168.1.5:8080/v1", api_key="none")
img = base64.b64encode(open("photo.jpg", "rb").read()).decode()
r = client.chat.completions.create(model="anything", messages=[{"role": "user", "content": [
    {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{img}"}},
    {"type": "text", "text": "What is in this picture?"}]}])
print(r.choices[0].message.content)
```

Or the web app's upload, or `chat.py` → `/image <path>`. The Anthropic `/v1/messages` route
takes an image block as usual.

## Knobs

- `--vision-tokens N` at setup / `vision.max_tokens` in the config (default 1,024 on GPU): more
  tokens = finer detail, slower encode. `--vision cpu` is the no-VRAM fallback (~10–30 s per
  picture, ~300 tokens).
- The encoder starts before the engine and takes its VRAM first; the engine sizes its expert
  cache around it.
