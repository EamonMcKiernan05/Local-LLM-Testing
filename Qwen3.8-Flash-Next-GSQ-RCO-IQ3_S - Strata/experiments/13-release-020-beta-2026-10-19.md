# 13 — v0.1.44 → v0.2.0-beta: engine 0.1.45.3, and the PLE shard the new read path exposed (2026-10-19)

v0.2.0-beta is the biggest release since the box was built: the repo becomes an app, a
terminal and an engine, and the engine package moves to **0.1.45.3**. For this box's path
(GSQ-RCO IQ3_S on CUDA sm_70) the release notes list no Volta-specific change — the new
speed defaults are sm_86, sm_60, gfx12, Intel Arc and the Linux file tier. Updated on the
box as served: stopped the server, checked out `v0.2.0-beta`, `STRATA_EXPERIMENTAL_SM60=1
./setup.sh --update`. The engine rebuilt for sm_70 against CUDA 12.9; setup reported every
model config up to date, so the config did not move.

**The first battery read a third slower — and the engine's own log said why.** Prefill on
the SATA-era setup: 577 / 1,237 / 1,397 / 1,391 / 1,478 / 1,314 tok/s. The startup banner
had a new line the 0.1.44 starts never printed:

```
WARNING: --ple-io direct measures slow here (10447 rows/s, about 43 MB/s of random 4 KiB
reads) ... (kept direct: pass --ple-io mmap or --ple-io ram to change it)
```

Every 0.1.44 start probed **58,128–72,813 rows/s**. The PLE/n-gram shard was a real file on
`/dev/sda3`, the Kingston A400 SATA boot SSD — the one remaining piece of the model set
still outside the NVMe storage policy. 0.2.0's read path asks for it in 4 KiB random pieces;
the A400 serves about 43 MB/s that way (a raw `dd` at QD1 measures 5.3 MB/s), where the NVMe
serves **76,986 rows/s** on the same probe. Moving the 28.8 GB shard to `/mnt/nvme` (sha256
verified, the SATA original kept as `.sata-original`, the `~/strata-ple` symlink re-pointed;
`/mnt/models` still resolves through the same chain) removed the warning and the deficit.

## Caveats

- **One battery on the new side.** The 0.1.44 side is the archived three-pass mean. A
  same-day re-run of 0.1.44 on the NVMe would settle whether the +2.2 % is engine or storage;
  it was not done, per instruction.
- **The storage rule is now load-bearing.** 0.2.0's 4 KiB random PLE reads turn the SATA
  boot SSD into a third-speed throttle. Keep `~/strata-ple` on the NVMe.
- **0.2.0 requires an API key for a non-loopback bind.** The server refuses `0.0.0.0` without
  one (`a non-loopback bind requires an inference API key`); this battery ran on
  `127.0.0.1`. The served config still carries `"host": "0.0.0.0"`.
- The new in-app harness/terminal (`strata launch`, `strata bench run`) was not exercised;
  the numbers here come from the same model-bench harness as every other experiment.
