# 01 — Platform bring-up and the storage policy (2026-09-30 to 10-01)

The box came back on 2026-09-30 as a fresh Ubuntu 24.04 with two Tesla V100 32 GB and no
inference software at all. Strata was installed the same day; the base model joined it on
2026-10-03 — **every measurement in this folder is the base IQ3_S.** Two things from the
bring-up shaped everything that follows. They are records of the setup work, not benchmarks, so
read them as the platform's ground rules.

## The n-gram shard belongs on NVMe

Strata reads its 28.8 GB n-gram table with **random unbuffered reads per token**. `/mnt/models`
is a spinning hard drive, each such read cost ~80 ms there, and the engine's own stage
breakdown put most of every decode step into waiting on it. The fix: copy the shard to the NVMe
and leave a **symlink** at the standard path (the HDD original kept beside it as
`.hdd-original`). On the NVMe the same reads cost ~0.1 ms.

This is the origin of the storage policy in [`HARDWARE.md`](../HARDWARE.md), and it is the single
biggest performance lever the box has: when decode is mysteriously slow, check the storage type
of every path the engine reads randomly before anything else.

Do **not** repoint the config at the NVMe path instead of symlinking: the loader discovers
shards by exact-path probe from `--native` and dies with `native dense: duplicate split shard
number` when a second shard 2 exists beside shard 1. Same file, standard paths, symlink swap.

## sm_70 needs a local build and two env flags

- **No prebuilt engine exists for the V100** (sm_70 is upstream-experimental): the build is
  local (CUDA 12.9), with `STRATA_EXPERIMENTAL_SM60=1` admitting the card and making setup add
  `-DSTRATA_EXPERIMENTAL_SM60=ON`.
- **The prompt-attention trap (upstream issue #371):** `qsa_prompt_attn_batch` mis-admits sm_70
  and traps the GPU — `prefill copy_i32: unspecified launch failure`, Xid 43, zero output
  tokens, crash loop. `STRATA_PROMPT_ATTN_OLD=1` skips a path that can never run on the V100 —
  permanently correct, not a perf compromise. Both flags are baked into the start wrapper
  ([`HARDWARE.md`](../HARDWARE.md) → start).

The base model was installed on 2026-10-03 (packs built, hot files moved to the NVMe, the 256K
window verified — experiment 02), and everything measured after that point is its.
