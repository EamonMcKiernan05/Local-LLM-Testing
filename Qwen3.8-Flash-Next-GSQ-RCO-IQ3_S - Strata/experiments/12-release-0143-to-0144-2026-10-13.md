# 12 — v0.1.43 → v0.1.44: same-day pair + agreement check (2026-10-13)

v0.1.44 (released 2026-10-13) is a big release for other platforms — Unsloth's UD-* files and
NVFP4 packs in setup, Qwen3.6-35B-A3B, faster AMD RDNA4 and Arc multi-GPU, an experimental Mac
(Metal) build — with v0.1.43.1's fixes folded in. For this box's path (GSQ-RCO IQ3_S on CUDA
sm_70) the release notes predict no change: "Answers on the default models are the same as
0.1.43.1 (byte-identical in our identity tests … )", and every default that changed touches
RDNA4 or Unsloth files only. Updated on the box as served (`setup.sh --update`, engine rebuilt;
configs md5-checked unchanged).

Measured as a controlled same-day pair: v0.1.43 was benched fresh while it was still live as
served (the pair's "before"), then the update to v0.1.44, six depths, one run each — only the
engine differs.

## Reading — parity; the decode dip is the before-side's own high cells

The agreement check: the fresh 0.1.43 re-run against its own 10-11 run landed −3.7 % prefill at
60K (the pair's one +3.9 % cell) and +8.8 / +9.8 % decode at 20 / 60K (±1.7 % elsewhere) — it sat
high exactly where the pair reads −7.5 / −4.5 %. Against the 10-11 numbers, 0.1.44's prefill
agrees within **±0.5 % at 20–200K** (+1.4 % at 250K) and its decode mean is −0.5 %, with single
cells swinging to ±6 % (100K −6.3, 250K −5.1) — the established single-rep band.

So: **no measurable speed change from v0.1.44 on this box** — the same parity read as
0.1.42 → 0.1.43, consistent with a release whose changes target other platforms.

### Decode repeats — the same night (three passes per side)

The pair's decode read was settled with repeats: two more batteries per side (0.1.43 rolled back
for its passes, 0.1.44 restored afterwards; all four runs 21:22–21:53 UTC, same protocol, same
config). Per depth, decode tok/s:

- **Net decode: −0.9 % over three passes (67.3 vs 66.7 six-depth means) — inside the
  pass-to-pass spread** (0.1.43: 68.1 / 67.2 / 66.6; 0.1.44: 65.9 / 67.2 / 66.8 — a 2.2 tok/s span across all six passes). Five of six depths
  overlap outright; the pair's −3.1 % was the 0.1.43 side's first-pass draw (76.3 at 20K, 71.4 at
  60K — neither repeated).
- The one cell the repeats do not cross: 250K decode (0.1.43 63.0–66.2, 0.1.44 60.8–62.7, means
  64.3 vs 61.7) — a ~2.7 tok/s lean left uncalled at three reps each, noted for a longer look.
- Prefill over the same repeats: +0.4 % net (1,943.7 vs 1,952.2 six-depth means) — the pair's parity read holds;
  at 60K the 0.1.43 side's 1,971 first pass did not repeat (2,034 / 2,041) while 0.1.44 stayed at
  2,048–2,055 on all three passes.
