## What is raw, what is derived

- **Raw** (`data/raw/`): the four model-bench run dirs exactly as the harness wrote them — `results.jsonl`
  (one row per arm), `meta.json` (endpoint, model, battery), `summary.csv`. `SHA256SUMS` covers all twelve
  files. Nothing in `data/raw/` was edited.
- **Derived** (`data/csv/`): `averages.csv` is the 2-run mean and per-run min/max per arm per depth;
  `means.csv` is the per-run rows the charts read; `facts.json` records the counts and the harness
  metadata. All three are regenerated by `scripts/build_data.py`, which asserts 4 runs, 12 arms, 3 depths
  per run, and that every run sliced the **same document** at each depth (the comparability proof — it
  refuses to write otherwise).
- **Charts** (`charts/`): rendered from `data/csv/means.csv` by `scripts/make_chart_depth.py`; no number on
  the card is typed by hand.

## Which numbers these are

Maya **v1.1.53** (`git describe --tags` on the box), engine `maya-ds4`, built for sm_70, driven by
`model-bench` 0.1.0. Config in `serving/maya-ds4-udiq1s-calibrated.json`; arms are that config with
`--suffix-draft 0` or `3` and nothing else. Calibration (`installer.calibration`,
`installer.speed_calibration` in the same file) was run by Maya's own tuner the night before:
`--tp 2` / `--tp 1` → same effective grouping (1/1, not compared), `--cpu-threads 20` kept,
DSpark drafter **rejected** at 9.16 against 11.18 tok/s.

Means are of **2 runs per arm**. Decode on this engine varies 27–48 % between loads; the per-run spread
is published in `data/csv/averages.csv` rather than hidden in a mean.

## What could not be reached

- **The 1 Nov v1.1.45 comparison in the README is archived, not re-measured.** That arm's quant had been
  swapped off the NVMe before this batch ran, and re-running v1.1.45 would need a tag checkout and a
  reconfigured box. The pair is quoted only as an update signal and is labelled as such.
- **The as-served original config is gone.** The tuner rewrites `maya-ds4-udiq1s-opt.json` in place; the
  pre-calibration file is `serving/maya-ds4-udiq1s-after-calibrate.json`'s ancestor and was not archived.
  What is archived is what served the bench.
- **Warm-up batteries are excluded by design** — they are 100K/200-token runs with a different `gen`, and
  including them would mix two battery shapes in one mean.
- The `--suffix-draft` arms answer a question about *prompt-lookup* drafting only; they say nothing about
  DSpark, which the tuner had already rejected on this box.
