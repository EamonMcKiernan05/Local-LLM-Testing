# DeepSeek-V4.1-Flash-1017 (UD-IQ1_S) on Strata 0.2.9 — the bench record on box .5

**2 recorded runs (6 measured arms), 0 failed.** unsloth **UD-IQ1_S** + Q6_K Engram (284,640,120,584
bytes) served by **Strata 0.2.9** (`strata-dsv41`, hand-built for sm_70) on **2× Tesla V100 32 GB**,
measured **2026-10-31** on box .5 at **131,072 context**. One run as shipped, one tuned. 400 tokens per
depth. No drafter: the set carries no Q6_K drafter and Maya's `dspark-xs2` had not been attached yet, so
speculative decoding was off in both arms.

This is the first time a 284 GB set was served on this rig by Strata, and it is the last Strata
measurement of this model file before the 1 Nov engine pair and the 5 Nov Maya re-runs.

**The findings:**

| | 20K | 60K | 100K |
|---|---:|---:|---:|
| as shipped, prefill / decode | 361.3 / 10.20 | 396.7 / 11.90 | 381.9 / 10.70 |
| tuned (`--prefill-chunk 16384 --cpu-threads 20`) | 422.2 / 8.10 | 552.9 / 8.30 | 600.8 / 7.90 |
| prefill gain from tuning | +16.9 % | +39.4 % | +57.3 % |
| decode cost of tuning | −20.6 % | −30.3 % | −26.2 % |

- **The tuning trades decode for prefill, hard.** +17 to +57 % prefill for −21 to −30 % decode: bigger
  prompt chunks feed the read phase and take threads off the expert lane. Choose by workload — long input
  with short output wants the tuned config, interactive chat does not.
- **Tensor parallel is refused**: `tensor parallel 2 -> 1`, 256-value IQ1_S blocks cannot split n_ff 2,304,
  so each card takes a layer group (0–20, 21–39 + head). Residency at load: 3,408 of 8,064 experts on card
  0, 564 MiB free.
- **One run per config**, so the percentages are a single draw each. The direction is solid; the exact
  magnitudes should be re-run before being quoted as the engine's numbers.

## Method

Strata `--pack <UD-IQ1_S>/maya-ds4 --max-context 131072 --eos 1 --vision off --tp 2`, arms differing only
by `--prefill-chunk 16384 --cpu-threads 20`. Fresh load per run, warm-up discarded. `model-bench` 0.1.0,
400 tokens, temperature 0.5, seed 12345, one rep per depth, 20K / 60K / 100K (150K+ skipped).
