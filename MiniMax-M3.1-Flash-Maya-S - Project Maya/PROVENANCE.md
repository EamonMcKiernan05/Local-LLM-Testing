**Which numbers these are:** Maya **v1.1.35**, the `maya-mm3` binary (MiniMax is its own architecture),
model `MiniMax-M3.1-Flash-Maya-GGUF` **Maya-S IQ2_XXS** — 3 shards, 122 GB decimal / 116 GiB, 428B total,
~23B active per the shipped `config.json`. `model-bench` 0.1.0, temperature 1.0 / top_p 0.95, seed 12345.

**Residency** (engine log): 2,849 of 7,296 routed experts in VRAM.

**Not covered:** one run, one rep per depth, and a 200-token battery at a 5K/20K/60K depth set — this was a
first-contact test of a new architecture, not a like-for-like sweep. The shape of the curve is the finding;
the individual figures are a single draw and must not be averaged with another model's.

## What is raw, what is derived

- **Raw**: `results.jsonl`, `meta.json`, `summary.csv` per run, copied byte-for-byte from
  `~/model-bench/runs/` on box .5 and hashed into `data/raw/SHA256SUMS`. The run-dir name each published
  file came from is in `scripts/runs.txt`.
- **Derived**: `data/csv/averages.csv` (mean and per-run min/max per arm per depth), `means.csv` (the
  per-run rows the card reads) and `facts.json`, regenerated by `scripts/build_data.py`, which asserts the
  run count per arm and that every run of an arm sliced the same document at each depth.
- **Chart**: rendered from the derived CSV by `scripts/make_chart.py`; no figure typed by hand.

## This is backfill

Published from the October 2026 record without re-running anything. The engines have moved on since (Maya
v1.1.35 → v1.1.53, Strata 0.2.3.1 / 0.2.9 → later releases), so this folder is the dated measurement, not a
current figure. It lives on the `backfill-2026-10-datasets` branch and deliberately does not edit the root
README — that file is shared, and a second branch touching it is a conflict to resolve by hand.
