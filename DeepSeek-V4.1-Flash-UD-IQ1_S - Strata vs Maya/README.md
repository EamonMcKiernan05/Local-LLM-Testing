# DeepSeek-V4.1-Flash-1017 (UD-IQ1_S) on Maya vs Strata — the 3-run engine pair on box .5

**12 recorded runs (36 measured arms), 0 failed.** One model file — unsloth **UD-IQ1_S** (284.6 GB) —
served by **two engines** on **2× Tesla V100 32 GB**, measured **2026-11-01** on box .5: Project Maya
**v1.1.45** and Strata **0.2.9** (`build-dsv41`, hand-built for sm_70). 131,072 context, three runs per
arm, four arms (each engine with its drafter on and off), 400 generated tokens per run.

The findings that matter:

- **Maya wins both axes at every depth, and the decode gap is large.** At 20K / 60K / 100K, drafter off:

| | 20K | 60K | 100K |
|---|---:|---:|---:|
| Maya v1.1.45 prefill / decode | 463.6 / 10.50 | 643.4 / 16.27 | **670.3 / 11.50** |
| Strata 0.2.9 prefill / decode | 425.9 / 7.87 | 561.3 / 8.07 | 609.5 / 8.30 |
| Maya drafter ON | 460.1 / 9.50 | 616.0 / 13.90 | 644.4 / 10.03 |
| Strata drafter ON | 371.4 / 7.97 | 516.1 / 8.17 | 536.5 / 8.03 |

  That is **+8.8 % / +14.6 % / +10.0 %** prefill and **+33 % / +102 % / +39 %** decode in Maya's favour.
- **The drafter loses on both engines and at every depth.** Acceptance was real — 66 % (Strata, 501 of
  759 drafts) and 77 % (Maya, 432 of 563) — and it still cost 3–15 % prefill and up to 15 % decode. Twelve
  runs, no exception.
- **Neither engine gets tensor parallel on this quant.** Both reduce `--tp 2` to a layer split: 2,304-wide
  expert planes do not halve into 256-value IQ1_S blocks. The Maya side still uses both cards, one layer
  group each.
- **The mechanism is residency, not engine cleverness.** Both sit at 6,705 of 15,360 experts in VRAM, with
  8,955 (67.5 GB) streaming off the NVMe — Maya's read path simply handles that lane better.
- **Prefill reproduces tightly, decode does not.** Maya drafter-off at 100K: 651.3 / 681.3 / 659.0 prefill
  per run (tight) but 9.7 / 12.9 / 11.9 decode. Read the means; treat the third significant figure as noise.

## Why this dataset exists next to the 2026-11-05 batch

The sibling folders `DeepSeek-V4.1-Flash-UD-IQ1_S - Project Maya` and
`DeepSeek-V4.1-Flash-Mia-EXL3-2.9bpw - Project Maya` re-run the **Maya** side of this pair on **v1.1.53**
with an extra quant. Maya's 5 Nov numbers (513.8 / 727.5 / 689.2 prefill and 12.00 / 16.10 / 16.05 decode)
therefore supersede Maya's 1 Nov row above for anyone asking "what does this box do on this model today".
**The Strata side has not been re-run** — 0.2.9 remains the last measured Strata figure for this file. The
comparison between the two batches is cross-day and cross-version; only a same-day pair settles a version
delta, so this folder keeps its own measurement intact rather than absorbing the newer one.

- `data/csv/` — `averages.csv` (means and per-run spread per arm per depth), `means.csv`, `facts.json`.
- `scripts/` — `runs.txt` (the run-dir mapping), `build_data.py` (asserts 12 runs, 3 per arm, and the same

- `PROVENANCE.md` — raw vs derived, engine versions, and the limits.

## Method

Every measured run had its own fresh load and a discarded 100K/200-token burn before it. Both engines were
run with the same tuned config: `--pack <pack> --max-context 131072 --eos 1 --vision off --tp 2
--prefill-chunk 16384 --cpu-threads 20`, differing only in the drafter flag (`--dspark on --suffix-draft 3`
or `--dspark none --suffix-draft 0` on Maya; `--dspark on|none` on Strata). The Mayas and the Stratas each
read their own pack of the same weight files, both rebuilt to carry Maya's 4.25 GB `dspark-xs2` drafter so
the flag had something to load on either engine. `model-bench` 0.1.0, 400 tokens, temperature 0.5, fixed
seed, one rep per depth.
